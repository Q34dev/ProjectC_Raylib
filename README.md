# Semester Project - Low-level programming in C

## 🔴🎮 A "Connect 4" game for 2 players 🎮🟡 

### Authors:
* Jakub Barcicki
* Olaf Wiśniewski

## 📝 Description:
A simple interactive game implemented entirely in C using the _Raylib_ library. This project fits all the requirements for a grade of 5.0, as it features:
* a Graphical User Interface (GUI)
* modular architecture
* operations on files
* dynamic memory management
* clear coding practices
* error handling

## 🔎 Instruction:
To play the game after unpacking the zip, launch the **main.exe** fail located in the main foler.

To configure game settings, edit the **config.txt** file located in the /files folder.

## ⚙️ Features:
* a full Connect 4 gameplay loop for two players
* mouse navigation and input
* auto-saving and loading the game state from the files/save.txt file
* reset and play again buttons
* custom art for the Connect 4 chips

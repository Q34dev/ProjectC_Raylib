# Semester Project - Low-level programming in C

## 🔴🎮 A "Connect 4" game for 2 players 🎮🟡 

### Authors:
* Jakub Barcicki
* Olaf Wiśniewski

## 📝 Description:
A simple interactive game implemented entirely in C using the _Raylib_ library. This project fits all the requirements for a grade of 5.0, as it features:
* a Graphical User Interface (GUI)
* modular architecture
* operations on files
* dynamic memory management
* clear coding practices
* error handling

## ⚙️ Features:
* a full Connect 4 gameplay loop for two players
* mouse navigation and input
* auto-saving and loading the game state from the files/save.txt file
* configuring game settings, such as the board dimensions
* reset and play again buttons
* custom art for the Connect 4 chips

## 🔎 Instruction:
The program was originally compiled on Windows using the Visual Studio Code IDE.
To compile the program (using Windows and the VS Code environment as an example):
1. Install the Raylib library. Tutorial:
* https://github.com/raysan5/raylib/wiki/Working-on-Windows
* (For Linux: https://github.com/raysan5/raylib/wiki/Working-on-GNU-Linux)
2. Open the unzipped project folder in Visual Studio Code.
3. Install a C language extension, for example:
* https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools-extension-pack
4. Compile the main.c file by pressing the F5 key.

To play the game:
* Launch the **main.exe** file located in the main directory.

To configure game settings:
* Edit the **config.txt** file located in the /files directory.
